# 1편 micrograd 실습 노트북

1편(micrograd: 신경망과 역전파를 손으로 만들기)을 직접 따라 치며 익히는 노트북입니다.
기본 실행 장소는 Colab(구글이 주는 무료 온라인 노트북)이고, 내 컴퓨터의 Jupyter는 선택입니다.

출처: 코드는 Andrej Karpathy의 micrograd, nn-zero-to-hero(MIT 라이선스)를 따라 만든 것입니다.
https://github.com/karpathy/micrograd · https://github.com/karpathy/nn-zero-to-hero (LICENSE 전문: `third_party/licenses/`)

## 채점 셀과 결과코드

단계마다 코드 셀 바로 아래에 채점 셀이 있습니다. 채점 셀은 고치지 않고 실행만 합니다.

| 표시 | 뜻 |
|---|---|
| `✓ 맞음: …` | 통과 |
| `✕ 다시: …` | 다름. 무엇이 다른지와 고칠 곳이 쉬운 말로 나옵니다 |
| `· 건너뜀: …` | 채점할 수 없음(예: torch가 없음) |
| `⚠ 채점기 오류: …` | 채점 프로그램 자체의 고장(내 탓 아님) |
| `○ 아직: …` | 이 노트북이 붙인 표시. 위 단계 셀을 아직 실행하지 않아 채점에 넘길 값이 없음 |

맨 끝 "마무리" 셀을 실행하면 채점표와 결과코드가 나옵니다. 맨 아래 줄(`Z2H1.`로 시작)을 복사해 앱의 "결과코드 붙여넣기" 칸에 넣습니다.
채점표의 L01-R1~R3(재구성 과제)는 이 노트북에서 채점하지 않으므로 "아직 안 함"으로 보입니다.

### 채점 셀이 예외를 내지 않게 한 방식 (한 가지로 통일)

모든 채점 셀은 같은 모양입니다. 가운데 `check(...)` 줄은 `z2h_check/README.md`의 "1편 호출 규약" 표 그대로입니다.

```python
# 채점 셀: 고치지 말고 실행만 하세요.
try:
    check("L01-S04", Value)
except Exception as _err:
    _z2h_not_yet("L01-S04", _err)
```

- `check()`는 원래 예외를 내지 않습니다. 예외가 날 수 있는 곳은 `check()`에 넘길 값을 만드는 순간뿐입니다(아직 없는 이름 `Value`, `n` 등을 쓰면 NameError, `draw_dot(d)`가 실패하면 그 오류).
- 그때 `_z2h_not_yet`(준비 셀 맨 아래에 정의)이 "○ 아직: …" 한 줄만 출력합니다. 채점 기록은 남기지 않으므로 채점표에는 "아직 안 함"으로 나옵니다.
- 표와 다르게 부르는 칸 3개(정본 코드가 넘길 이름을 만들지 않아서)
  - L01-S02: 정본 셀은 숫자 기울기를 이름 없이 마지막 줄로 보여 줍니다. 채점 셀은 그 보여 준 값(IPython의 `Out` 기록 중 가장 최근 값)을 `_z2h_shown()`으로 넘깁니다. 준비 셀의 `___ = None` 때문에 IPython이 `_`를 더 이상 바꾸지 않아 `_` 대신 `Out`을 씁니다.
  - L01-S03: 정본 셀은 기울기를 print로만 보여 줍니다. 채점 셀은 셀이 만든 `d1`, `d2`, `h`로 `(d2 - d1) / h`를 다시 계산해 넘깁니다.
  - L01-S16: 눈으로 비교하는 단계라 `check("L01-S16", seen=True)`입니다. 빈 노트북에서 "맞음"이 나오지 않도록 학습 셀이 만든 `n`, `loss`가 있을 때만 부릅니다.

## 앞 셀을 고치는 단계

L01-S05처럼 앞 셀(주로 L01-S04 칸에 쓴 Value 클래스 셀)을 고치는 단계가 있습니다.
- 학생용: 안내 글의 "앞 셀 고치기"(고칠 셀, 넣을 곳, 줄 수)와 "실행 순서"를 보고, 위로 올라가 그 셀을 고친 뒤 다시 실행합니다. "먼저 다시 실행할 칸"이 있으면 그 셀도 다시 실행합니다(클래스를 고치기 전에 만든 Value 상자는 옛 설계도를 쓰기 때문).
- 정답용: 교사 `test_content.py`와 같은 순서로 "고친 뒤의 셀 전체"와 "다시 실행할 칸"을 그 단계 자리에 다시 둡니다.
