## 채점 셀과 결과코드

채점 셀은 `check("L01-S02", globals())` 한 줄이고, 고치지 않고 실행만 합니다. 채점 기준은 정본 `expected_check` 그대로입니다(`z2h_check/README.md`).

| 정본 모양 | 칸 수 | 채점 셀이 보는 것 |
|---|---|---|
| `value_range` + `expr` | 23 | 정본 확인 식(예: `f(3.0)`, `len(d._prev)`)을 내 이름 공간에서 계산한 값이 min~max 안인지. 식의 이름이 아직 없으면 "○ 아직" |
| `output_match` | 15 | 바로 위 '내 셀'이 보인 글(print 출력 + 마지막 줄 값)에 정본 기대 출력이 있는지. 소수는 1e-6까지 같으면 맞음 |
| `value_range`(식 없음) | 1 | 바로 위 셀 출력의 마지막 숫자가 min~max 안인지(L01-S51) |
| `manual` | 14 | 바로 위 셀이 오류 없이 돌았는지만. 통과로 기록하되 "✓ 실행됨"으로 보입니다. 그림의 숫자는 '보여야 하는 것'의 '스스로 확인할 것' 목록으로 직접 확인 |
| 재구성 `check_code` | 3 | 정본 확인 셀을 내 이름 공간의 사본에서 실행한 출력이 정본 통과 기준(`pass_ko`)과 맞는지 |

| 표시 | 뜻 |
|---|---|
| `✓ 맞음: …` | 통과 |
| `✓ 실행됨: …` | 그림 단계 통과(셀이 오류 없이 돌았음). 그림의 숫자는 위 목록으로 직접 확인. 결과코드에는 통과로 들어감 |
| `✕ 다시: …` | 다름, 또는 바로 위 셀에서 오류. 무엇이 다른지와 고칠 곳이 쉬운 말로 나옵니다 |
| `○ 아직: …` | 위 셀을 아직 실행하지 않았거나 빈 셀 그대로. 기록하지 않음(채점표에 "아직 안 함") |
| `· 건너뜀: …` | 셀 출력을 읽을 수 없는 곳(IPython 이 아님) |
| `⚠ 채점기 오류: …` | 채점 프로그램 자체의 고장(내 탓 아님) |

"바로 위 셀이 보인 것"을 읽는 법: 채점 도구 준비 셀이 IPython(Jupyter, Colab)의 셀 실행 앞뒤 알림에 작은 함수를 걸어(`z2h_check/runs.py`),
셀이 끝날 때마다 그 셀의 출력 글, 마지막 줄 값, 오류를 기억합니다. 채점 셀과 준비 셀은 기억하지 않으므로, 채점 셀을 두 번 눌러도 바로 위 '내 셀'을 봅니다.
`# 여기에 작성` 처럼 주석뿐인 셀은 "빈 셀"로 봅니다.

맨 끝 "마무리" 셀을 실행하면 채점표와 결과코드가 나옵니다. 맨 아래 줄(`Z2H1.`로 시작)을 복사해 앱의 "결과코드 붙여넣기" 칸에 넣습니다.
결과코드에는 채점 칸 56개(코드 단계 53 + L01-R1~R3) 중 통과(`p`)와 다시(`f`)만 들어갑니다. 결과코드 모양은 바뀌지 않았습니다(`Z2H1.{base64url(JSON)}.{crc32}`, JSON 칸 `v,l,p,f,t`).

## 채점이 잡는 버그와 못 잡는 버그 (`tests/test_l01_variants.py`)

정본 정답 코드를 글자 치환으로 한 곳씩 틀리게 바꾸고 본문을 다시 돌려, 그 버그가 어느 칸에서 "✕ 다시"가 되는지 봅니다(2026-11-17 실측).

| 틀리게 바꾼 것 | 반드시 ✕ 인 칸 | 함께 ✕ 가 된 칸 |
|---|---|---|
| 곱셈 `_backward` 재료 바꿔 씀 | S28 | S52, S53, S54 |
| 더하기 `_backward` 한쪽 누락 | S27 | S52, S53, S54 |
| tanh 기울기 `(1 - t**2)` → `(1 - t)` | S52 | 없음 |
| `+=` 대신 `=` | S53 | S52, S54 |
| 위상 정렬을 뒤집지 않음 | S49 | S52, S53, S54 |
| `backward()`의 `self.grad = 1.0` 누락 | S31 | S49, S52, S53, S54 |
| 기울기 비우기 누락 | S53 | S54 |
| 갱신 부호 반대 | S53 | S52, S54 |
| 거듭제곱 기울기 지수 `other - 1` → `other` | S53 | S52, S54 |
| 뉴런 편향 누락 | S51 | S52 |
| 식 f 의 상수 누락 | S02, S03 | 없음 |

채점이 못 잡는 변형(어느 단계 칸도 ✕가 되지 않음, 시험이 "여전히 못 잡음"을 확인)
- exp 기울기 오류(`self.grad += out.data * out.grad` → `self.grad += out.grad`): exp 를 쓰는 단계는 S36(확인 식이 값만 봄)과 S39(그림, manual)뿐이고 학습에는 exp 가 없습니다. S39 그림의 기울기 숫자를 학습자가 스스로 확인해야 잡힙니다.
- tanh 기울기 오류는 tanh 를 가르치는 S28 칸이 아니라 S52(비우기 없는 학습의 손실 범위)에서만 잡힙니다. S28 확인 식은 곱셈만 봅니다.
