## 1. 켜기 (맥미니 터미널, 저장소 폴더에서)

앱 화면 파일을 만든다(1분 안팎). 끝에 `Complete!`와 `문구 검사 통과`가 보이면 정상이고, 빨간 오류가 나오면 그 화면을 CTO에 보여 준다.
```
cd app && npm run build && cd ..
```
진도 서버를 켠다. `Z2H 진도 서버: http://127.0.0.1:8787/`이 보이고 멈춘 듯 기다리면 정상이다. 끄려면 그 창에서 Ctrl + C.
```
cd server && ../.venv/bin/python -m z2h_server
```
맥미니의 브라우저에서 `http://127.0.0.1:8787/`을 연다.

- 잘못된 경우: `address already in use`가 나오면 이미 켜져 있는 것이다. 브라우저에서 바로 열면 된다.
- 기록은 `server/data/z2h.sqlite3` 파일 하나에 쌓인다. 처음부터 다시 하려면 서버를 끄고 이 파일을 지운 뒤 다시 켠다(지우면 그 기록은 되돌릴 수 없다).

## 2. 해 볼 순서 (약 1시간)

| 순서 | 화면 | 볼 것 |
|---|---|---|
| 1 | `/` 랜딩 | "예시 화면" 표시가 있는 문구 초안. 문구는 공개 전 승인 항목 |
| 2 | `/taste/` 맛보기 | 노트북을 받아 Colab에 올리고 8단계를 따라 한다. 단계마다 "직접 확인했어요 · 완료". 끝 화면에서 이름 10줄을 붙여 넣는다 |

| 4 | `/home/` 학습 홈 | 이어서 하기, 실습 시간(자동과 수정) |
| 5 | `/lectures/L01/` 1편 개요 | 노트북 받기, 단계 목록, 익힘 기준, 결과코드 붙여넣기 |
| 6 | 1편 단계 몇 개 | 영상 구간, 따라 하기(예측 먼저, 줄별 풀이, 바뀐 줄만), 확인 문제, 힌트 4단계 |
