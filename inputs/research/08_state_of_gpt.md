## 1. 다루는 개념과 나오는 순서

설명란 요지: ChatGPT 같은 GPT 비서의 학습 파이프라인(토큰화, 사전학습, 지도 미세조정, 인간 피드백 강화학습 RLHF)과, 이 모델을 잘 쓰는 실전 기법과 사고방식(프롬프팅, 미세조정, 도구 생태계, 앞으로의 확장)을 다룹니다.

1부: GPT 비서를 어떻게 만드나
1. 4단계 파이프라인: 사전학습, 지도 미세조정(SFT), 보상 모델링(RM), 강화학습(RL). 사전학습이 학습 연산의 99%를 차지(자막 0:01:30)
2. 데이터 수집: 여러 출처를 섞은 데이터 혼합(Meta LLaMA 논문 예시, 자막 0:02:00)
3. 토큰화: 텍스트를 정수로, BPE(자막 0:03:00)
4. 예시 모델 2개(GPT-3와 LLaMA) 규모 비교
5. 사전학습 결과인 베이스 모델은 강력한 일반 표현을 배우지만 "문서 완성기"일 뿐임, 베이스 모델에 프롬프트로 일 시키기
6. SFT: 질문과 좋은 답 데이터로 이어서 학습(자막 0:11:30)
7. RLHF: 보상 모델 데이터셋(답변 비교), 보상 모델 학습, 강화학습
8. 모드 붕괴(mode collapse): RLHF 모델은 다양성이 줄어듦, 베이스 모델이 나은 경우

2부: GPT를 잘 쓰는 법
9. 사람의 생각과 모델의 토큰 단위 처리 차이: "트랜스포머는 생각하려면 토큰이 필요하다"(자막 0:25:00)
10. 여러 번 시도 후 고르기(앙상블), 스스로 점검하게 하기(reflection)
11. System 1과 System 2 비유, Tree of Thought 같은 트리 탐색과 AlphaGo 비유, AutoGPT(자막 0:27:30~0:29:30)
12. "Let's think step-by-step" 같은 프롬프트(자막 0:31:00)
13. 도구 사용과 플러그인, 검색 증강(retrieval-augmented) 모델(자막 0:33:00)
14. 제약된 프롬프팅(출력 형식 강제, 자막 0:34:30)
15. 미세조정: LoRA 같은 파라미터 효율 미세조정으로 일부만 학습하면 저렴해짐, 다만 기술적으로 더 까다로움(자막 0:35:30~0:36:00)
16. 기본 권장사항, 한계(편향, 환각, 추론 오류, 지식 마감일, 프롬프트 인젝션 등, 자막 0:39:30), 완전 자율 에이전트보다 영감과 제안의 원천, 코파일럿처럼 쓰라는 권고(자막 0:40:00)
