힌트

b = a + a에서 a.grad가 1.0으로 나옵니다. 고칠 곳은? · 제출 결과 다시

힌트 사다리

  1. 1. 질문으로 생각하기열림
    a가 b에 영향을 주는 길은 몇 개인가요?
  2. 2. 개념과 위치 짚기열림
    두 길의 기울기를 합쳐야 합니다. 단계 12(L01-S12)와 _backward 안의 self.grad = 줄을 보세요.
    기초 F-M2 연쇄 법칙 감각으로 돌아가 보기 ↗
  3. 3. 빈칸 코드

    정답에서 핵심만 빈칸으로 둔 코드를 줍니다.

    앞 힌트를 본 뒤 답을 한 번 더 냈습니다. 지금 열 수 있습니다.

    이 힌트를 열면 이 문제는 50%로 계산되고, 다음 복습에 다시 나옵니다.

  4. 4. 정답과 줄별 풀이답을 한 번 더 내거나 30분 뒤 열림

이 문제 힌트: 2 / 4 · 이 문제는 80%로 계산됩니다

다음:코드를 고친 뒤 답을 다시 내기
문제로 돌아가 다시 답하기

상태 (명세 참고용)

A. 아무것도 안 엶

  1. 1. 질문으로 생각하기

    생각할 방향을 질문 하나로 줍니다.

    이 힌트는 점수에 영향이 없습니다.

  2. 2. 개념과 위치 짚기1단계를 본 뒤 답을 한 번 더 내면 열림
  3. 3. 빈칸 코드답을 한 번 더 내거나 15분 뒤 열림
  4. 4. 정답과 줄별 풀이답을 한 번 더 내거나 30분 뒤 열림

B. 3단계 열림

  1. 1. 질문으로 생각하기열림
    a가 b에 영향을 주는 길은 몇 개인가요?
  2. 2. 개념과 위치 짚기열림
    두 길의 기울기를 합쳐야 합니다. 단계 12(L01-S12)와 _backward 안의 self.grad = 줄을 보세요.
    기초 F-M2 연쇄 법칙 감각으로 돌아가 보기 ↗
  3. 3. 빈칸 코드열림
    self.grad ___ 1.0 * out.grad
  4. 4. 정답과 줄별 풀이

    정답 코드 전체와 줄마다 풀이를 줍니다.

    앞 힌트를 본 뒤 답을 한 번 더 냈습니다. 지금 열 수 있습니다.

    이 힌트를 열면 이 문제는 0%로 계산됩니다. 완료는 인정되고, 내일 비슷한 새 문제로 다시 해 볼 수 있습니다.

C. 4단계까지 열림 + 도움 요청

  1. 1. 질문으로 생각하기열림
    a가 b에 영향을 주는 길은 몇 개인가요?
  2. 2. 개념과 위치 짚기열림
    두 길의 기울기를 합쳐야 합니다. 단계 12(L01-S12)와 _backward 안의 self.grad = 줄을 보세요.
    기초 F-M2 연쇄 법칙 감각으로 돌아가 보기 ↗
  3. 3. 빈칸 코드열림
    self.grad ___ 1.0 * out.grad
  4. 4. 정답과 줄별 풀이열림
    self.grad += 1.0 * out.grad
    =는 덮어쓰고 +=는 더합니다. a가 두 길로 쓰였으니 두 길의 기울기를 더해야 2.0이 됩니다.
  5. 도움 요청 메모

    정답을 넣어도 결과가 다르면 대개 설치나 장치 문제입니다. 내 코드, 에러 마지막 줄, 환경을 정리한 메모를 만듭니다. 이 화면에만 저장되고 자동으로 보내지 않습니다.
