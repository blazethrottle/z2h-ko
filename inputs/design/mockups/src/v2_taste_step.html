더하기의 기울기 구하기

무엇을 하는 단계인지: 두 숫자를 더한 결과에서 거꾸로 가며, 각 숫자가 결과에 주는 영향(기울기)을 구합니다.

앞 단계에서 만든 Value 상자(덧셈과 backward 포함)가 이미 준비되어 있습니다. 준비된 코드 보기

코드 5줄 · 브라우저에서 바로 실행
1a = Value(2.0)
숫자 2.0을 담은 상자 a
2b = Value(-3.0)
숫자 -3.0을 담은 상자 b
3c = a + b
더하기. c는 a와 b가 재료라는 것을 기억합니다
4c.backward()
c에서 거꾸로 가며 기울기를 채웁니다
5print(a.grad, b.grad)
a와 b의 기울기를 봅니다
