01함수 그래프 그리기긴 단계
신경망도 결국 입력을 넣으면 출력이 나오는 큰 함수입니다. 오늘은 이런 함수의 "기울기"를 직접 재고 계산합니다. 완료02숫자 기울기
x를 아주 조금 올리면 f는 그 약 14배만큼 오릅니다. 기울기는 "조금 바꾸면 몇 배로 변하나"입니다. 완료03입력이 여러 개일 때긴 단계
d를 a로 미분하면 b가 나옵니다. `a += h`를 `b += h`로 바꾸면 2.0(a의 값), `c += h`로 바꾸면 1.0이 나오는지 직접 해 봅니다. 완료04Value 클래스 뼈대긴 단계
평범한 숫자에 "기울기 칸"과 "족보(재료 기록)"를 붙였습니다. 이 두 칸이 역전파의 전부입니다.● 지금05덧셈과 곱셈 기록하기긴 단계앞 셀 고침
계산할 때마다 "누가 누구로 만들어졌는지"가 그물(계산 그래프)로 남습니다.○ 아직06계산 그래프 그림긴 단계준비 코드
역전파는 이 그림을 오른쪽(결과)에서 왼쪽(재료)으로 거슬러 가는 일입니다.○ 아직07손으로 기울기 채우기긴 단계
+ 는 기울기를 그대로 나눠 주고, * 는 상대 값을 곱해 전합니다. 결과에서 거꾸로 곱해 오는 것이 연쇄 법칙입니다.○ 아직08한 걸음 움직여 보기긴 단계
기울기는 "어느 쪽으로 움직이면 결과가 커지는지" 알려 줍니다. 학습은 이것을 반대로(손실을 줄이는 쪽으로) 쓰는 일입니다.○ 아직09뉴런 하나 계산하기긴 단계
뉴런은 "입력 × 가중치의 합 + 편향"입니다. 여기까지는 S05에서 만든 +와 *만 씁니다.○ 아직09btanh 붙이기긴 단계앞 셀 고침
뉴런의 출력은 합에 tanh를 씌운 값입니다. 이 활성화 함수 덕분에 신경망이 곡선 모양도 배울 수 있습니다.○ 아직10_backward를 + 와 * 안에 넣기긴 단계앞 셀 고침
S07에서 손으로 한 규칙을 각 계산 안에 넣어, 결과 상자가 "내 기울기를 재료에게 어떻게 나눌지"를 스스로 알게 했습니다.○ 아직10btanh의 _backward긴 단계앞 셀 고침
각 상자가 자기 _backward를 부르면 기울기가 한 칸씩 왼쪽으로 갑니다. 이것을 모든 상자에 순서대로 하면 역전파입니다.○ 아직11위상 정렬긴 단계
재료가 늘 결과보다 앞에 섭니다. 이 목록을 거꾸로 돌면, 결과 쪽 기울기가 다 모인 뒤에 재료로 넘어갑니다.○ 아직11bbackward() 메서드긴 단계앞 셀 고침
손으로 하던 역전파가 `o.backward()` 한 줄이 되었습니다. PyTorch의 `loss.backward()`도 같은 일을 합니다.○ 아직12같은 값을 두 번 쓰는 버그
a에서 b로 가는 길이 두 개라 기울기 1이 두 번 와서 2가 됩니다. S10에서 `=`가 아니라 `+=`로 쌓았기 때문입니다. (해 보기: `__add__`의 `+=`를 `=`로 바꾸면 1.0이 나오는 것을 확인하고 다시 되돌립니다.)○ 아직13숫자와 섞어 계산하기긴 단계앞 셀 고침
이제 `a + 1`, `1 + a`, `2 * a`처럼 평범한 숫자를 섞어 쓸 수 있습니다. S15의 `sum(...)`이 0부터 더하기 때문에 `__radd__`가 꼭 필요합니다.○ 아직13bexp와 빼기긴 단계앞 셀 고침
빼기는 새 규칙 없이 "더하기 + 부호 바꾸기"로 만들었습니다. 이미 만든 연산을 조합하면 기울기도 저절로 맞습니다.○ 아직13c거듭제곱과 나누기긴 단계앞 셀 고침
나누기도 "곱하기 + 거듭제곱"으로 만들었습니다. S15의 손실 `(yout - ygt)**2`가 이 단계의 빼기와 거듭제곱을 씁니다.○ 아직13dtanh를 쪼개서 다시 계산하기
같은 계산을 큰 덩어리(tanh) 하나로 하든 작은 연산 여러 개로 쪼개든 기울기는 같습니다. 덩어리를 얼마나 크게 둘지는 만드는 사람이 정합니다.○ 아직13ePyTorch로 비교긴 단계
우리가 만든 micrograd와 PyTorch는 같은 역전파를 합니다. PyTorch는 숫자 하나 대신 텐서(숫자 묶음)로 빠르게 할 뿐입니다.○ 아직14Neuron 클래스긴 단계
S09에서 손으로 만든 뉴런을 설계도로 만들었습니다. 가중치는 무작위로 시작해 학습으로 고쳐집니다.○ 아직14bLayer 클래스긴 단계
층은 같은 입력을 여러 뉴런이 동시에 보는 것입니다.○ 아직14cMLP 클래스와 parameters()긴 단계
신경망은 층을 이은 것이고, 학습이란 이 41개 숫자를 조금씩 고치는 일입니다.○ 아직15데이터와 손실긴 단계
손실은 "얼마나 틀렸나"를 숫자 하나로 모은 것입니다. 0이면 다 맞힌 것입니다.○ 아직15b학습 반복긴 단계
이것이 신경망 학습의 전부입니다: 예측하고, 틀린 정도를 재고, 기울기를 구해, 반대로 조금 움직이기. 큰 AI도 같은 반복을 아주 크게 할 뿐입니다.○ 아직16grad 비우기를 빼먹는 버그앞 셀 고침
기울기는 `+=`로 쌓이므로, 반복마다 비우지 않으면 지난 반복의 기울기가 섞여 걸음이 엉뚱하게 커집니다. Karpathy도 영상에서 이 실수를 했고, 문제가 쉬워서 우연히 잘 된 것처럼 보였다고 직접 말합니다.○ 아직
