_backward를 + 와 * 안에 넣기 긴 단계

  1. 1
    입력할 것Value 클래스 셀 세 곳에 줄을 더하고 다시 실행합니다. 이 단계는 실행 결과가 따로 없고, 확인은 S10b에서 합니다.
  2. 2
    보여야 하는 것클래스 셀이 에러 없이 실행됩니다. 화면에 따로 보이는 것은 없습니다.
  3. 3
    그 뜻S07에서 손으로 한 규칙을 각 계산 안에 넣어, 결과 상자가 "내 기울기를 재료에게 어떻게 나눌지"를 스스로 알게 했습니다.
바뀐 줄만 · L01-S04 Value 클래스 셀

흐린 줄은 이미 있는 기준 줄입니다. 그 바로 아래에 밝게 표시한 줄을 넣습니다. 세 곳을 모두 넣은 뒤 셀을 다시 실행하세요.

1 / 3 · __init__ 안, self.grad = 0.0 바로 아래 · 1줄 넣기

…        self.grad = 0.0        self._backward = lambda: None…

2 / 3 · __add__ 안, out = ... 줄과 return out 사이 · 4줄 넣기

…        out = Value(self.data + other.data, (self, other), '+')        def _backward():            self.grad += out.grad            other.grad += out.grad        out._backward = _backward…

3 / 3 · __mul__ 안, out = ... 줄과 return out 사이 · 4줄 넣기

…        out = Value(self.data * other.data, (self, other), '*')        def _backward():            self.grad += other.data * out.grad            other.grad += self.data * out.grad        out._backward = _backward…

줄별 풀이 (넣는 순서대로)

  1. 기울기를 재료에 나눠 주는 함수 칸. 처음엔 아무것도 안 하는 함수입니다
  2. 덧셈 결과의 기울기를 재료에게 나눠 주는 함수입니다
  3. 덧셈은 받은 기울기를 그대로 전합니다. 더하기(+=)로 쌓습니다
  4. 상대에게도 그대로 전합니다
  5. 이 함수를 결과 상자에 저장해 둡니다(나중에 부름)
  6. 곱셈 결과의 기울기를 재료에게 나눠 주는 함수입니다
  7. 곱셈: 상대 값 × 받은 기울기(S07에서 손으로 한 것)
  8. 상대는 내 값 × 받은 기울기
  9. 결과 상자에 저장해 둡니다
