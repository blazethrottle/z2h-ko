### 0.3 숫자·빈 값
- 진도, 시간, 단계 위치, 타임스탬프는 `tabular-nums`.
- 값이 없으면 "–" (en dash 하나). 0과 "–"는 다르다: 0은 기록이 있는데 0, "–"는 아직 기록이나 정의가 없음.
- 변화는 "▲+3", "▼-1"처럼 기호 + 부호 + 숫자. 색은 `ink-muted` 그대로 둔다 (좋고 나쁨을 색으로 판정하지 않음).

### 0.4 문구 원칙
- 존댓말, 짧게. 연속 기록(스트릭), 순위, "벌써 3일째 안 하셨어요" 같은 죄책감 문구, 축하 폭죽 없음.
- 틀렸을 때는 "다시"와 이유만. "아쉬워요", "틀렸습니다!" 같은 감정 문구 없음.
- em dash(U+2014) 금지. 범위는 en dash(–) 또는 "~".

### 0.5 영상 플레이어 `video-player` (2026-11-16 19:43 결정 반영)
- 공식 YouTube 임베드, 도메인 `www.youtube-nocookie.com`.
  - 주소 형식: `https://www.youtube-nocookie.com/embed/{videoId}?start={초}&end={초}&rel=0&playsinline=1`
  - **autoplay 매개변수를 넣지 않는다.** iframe `allow`에도 `autoplay`를 넣지 않는다: `allow="encrypted-media; picture-in-picture; fullscreen"`.
  - iframe에 `title="영상 19:09–32:10: {단계 이름}"`, `loading="lazy"`, `referrerpolicy="strict-origin-when-cross-origin"`.
- 크기: 16:9 (`aspect-ratio: 16/9`), 카드 폭 100%.
- 카드 구성 (위에서 아래)
  1. 머리줄: "영상 19:09–32:10" (`title-3` 크기, 숫자 `tabular-nums`) + "약 13분" `caption` + 오른쪽 접기/펼치기 `btn-ghost` (`aria-expanded`).
  2. 플레이어 칸.
  3. 아래줄: 왼쪽 "유튜브에서 열기 ↗" 링크 (`https://www.youtube.com/watch?v={id}&t={초}s`, 새 창, 최소 44 높이), 오른쪽 "32:10에서 멈춥니다" `caption`.
- 상태
  | 상태 | 모습 | 문구 |
  |---|---|---|
  | 접힘 | 머리줄만 (높이 56) | 버튼 "펼치기" |
  | 불러오는 중 | 플레이어 칸 `code-bg`, 가운데 문구 + 막대 1개. 움직임 없음 | "영상을 불러오는 중입니다" / "오래 걸리면 아래 유튜브에서 열기를 쓰세요" |
  | 준비됨 | YouTube 썸네일 + 재생 버튼. 사용자가 눌러야 재생 | (YouTube 기본 UI) |
  | 오류 | 플레이어 칸 `paper-sunken`, `retry` 제목 + 큰 버튼 하나. 아래줄 링크는 숨김 (버튼과 중복) | "✕ 이 화면에서 영상을 열 수 없습니다" / "인터넷 연결이나 유튜브 설정 때문일 수 있습니다" / 버튼 "유튜브에서 19:09부터 보기 ↗" |
- 오류 판정: iframe `load`가 10초 안에 오지 않거나, YouTube IFrame API `onError`(2, 5, 100, 101, 150)가 오면 오류 상태. IFrame API를 쓰는 경우에도 `autoplay`, `playVideo()` 자동 호출은 하지 않는다.
- 접힘 상태 기억: 기기별로 저장 (`localStorage`). 처음 값은 화면마다 아래 3, 4번 명세를 따른다.
- 영상 전체를 앱에 내려받거나 다시 올리지 않는다 (브리프 규칙). 임베드와 링크만.

## 2. 강의 개요 (`s2_lecture`)
- 머리: "강의 01 · 영상 2:26", 제목, 한 줄 설명, 배지 (12단계, 실습 예상 시간, ✓ 3 완료), 진행 막대, 다음 줄.
- 단계 목록: 번호 2자리, 단계 이름 (`label` 굵기), 한 줄 요약 (`small`, `ink-muted`), 오른쪽 상태.
  - 완료: "✓ 완료" `correct`
  - 지금: 행 바탕 `accent-tint` + 왼쪽 3px `accent`, "● 지금"
  - 아직: "○ 아직" `ink-muted`
- 잠금 없음. 앞 단계를 건너뛰고 열면 구간 화면 위에 "앞 단계 3을 아직 안 했습니다. 그대로 진행해도 됩니다." 한 줄 안내.
- 접근성: 목록은 `<ol>`, 현재 행 `aria-current="step"`.

## 3. 강의 구간 (`s3_segment`)

3. "이 단계에서 하는 일:" 한 문장.

데스크톱: 왼쪽 본문, 오른쪽 300px 단계 목록 (현재 `accent-tint`). 플레이어는 본문 열 폭 (약 820px) 16:9.

| 줄별 풀이 (데스크톱 1024+) | 2단 격자: 왼쪽 코드 줄 (`code-bg`), 오른쪽 같은 높이의 풀이 (`paper-raised`, `body-lg` 15~17). 행 높이는 둘 중 긴 쪽에 맞춤. 줄에 마우스를 올리거나 포커스하면 그 행 강조: 코드 `code-bg-sel`, 풀이 `accent-tint` + 왼쪽 3px `accent` |
| 줄별 풀이 (모바일) | 코드 줄 다음에 풀이가 쌓이는 1단. 풀이는 접힌 상태, 줄을 누르면 그 아래로 펼침 (여러 줄 동시 열기 가능). 줄 오른쪽 "풀이 ▾ / 풀이 접기 ▴". 긴 줄은 가로 스크롤하지 않고 줄바꿈 (들여쓰기 유지). 줄 행 최소 높이 44 |
| 예상 출력 | `paper-sunken` 상자, `font-code`. 숫자가 매번 달라지는 단계는 위에 "숫자는 조금 달라도 됩니다" 표시 (단계 데이터 `outputVaries: true`) |
| 내 결과 붙여넣기 → 비교 | 라벨 + `textarea` (`font-code`, `line-strong` 테두리) + 주 버튼 "비교하기" |
| 비교 결과 | ✓ "맞음: 예상 출력과 같습니다." / ✕ "다시: {어디가 다른지}. {어느 줄을 볼지}." / 빈 입력: "비교할 결과가 비어 있습니다" (9번 상태) |
| 오른쪽 패널 (데스크톱) | 영상 플레이어 → "막혔나요?" 힌트 카드 (6번) → 진행 카드 ("단계 4 / 12 · 따라 하기 2 / 3", 막대, 다음 줄, 이전 / "확인 문제로") |
| 모바일 패널 | 위 3개를 본문 아래에 쌓음 |

비교 규칙 (CTO 구현용)
1. 앞뒤 공백, 줄 끝 공백, 줄바꿈 종류(CRLF/LF) 무시.
2. 줄 단위로 비교해 처음 다른 줄과 그 안의 다른 부분을 찾는다.
3. `outputVaries` 단계는 숫자를 단계 데이터의 허용 오차로 비교하고, 모양(글자 부분)만 정확히 맞춘다.
4. 다르면 "어디가 다른지"는 자동 문장, "어느 줄을 볼지"는 단계 데이터의 `mismatchHints`에서 고른다 (교사 몽키 작성). 없으면 "힌트 사다리를 열어 보세요"로 대신.
5. 비교 결과 ✕가 나와도 힌트를 자동으로 열지 않는다. 힌트 카드 테두리만 `accent`로 바꿔 위치를 알려 준다.

접근성: 모바일 줄은 `role="button"` + `aria-expanded` + `aria-controls`, Enter/Space로 열기. 데스크톱 2단은 화면 읽기 프로그램을 위해 DOM에서 코드 줄 다음에 풀이가 오도록 둔다 (시각만 2단). 코드 블록 전체 복사 외에 줄 하나 복사는 넣지 않는다 (한 번에 붙여넣기가 실수가 적음).

## 5. 확인 문제 (`s5_quiz`)
- 머리: 위치, "확인 문제 2개", "틀려도 괜찮습니다. 틀린 문제는 복습 목록에 넣어 며칠 뒤 다시 보여 드립니다."
- 고르기 문제: 선택지 행 최소 56, `line-strong` 테두리. 누르는 즉시 채점 (확인 버튼 없음).
  - 고른 답이 맞음: 그 행 2px `correct` 테두리 + `correct-tint` + 오른쪽 "✓ 맞음".
  - 고른 답이 틀림: 그 행 `retry` 테두리 + "✕ 다시", 정답 행에 "✓ 정답" 표시.
  - 아래 결과 상자에 풀이 2~3문장.
- 짧은 답 문제: `input` + "확인" 버튼 (Enter 가능). 채점은 공백·대소문자·따옴표 차이 무시, 허용 답 목록 (교사 몽키 작성).
- 틀리면 "이 문제는 복습 목록에 넣었습니다. 1일 뒤 다시 보여 드립니다."
- 끝: 다음 줄 + "실습으로 돌아가기" / 주 버튼 "단계 4 마치기".
- 데스크톱: 문제 2개를 2열. 모바일: 1열.
- 접근성: 선택지는 `role="radiogroup"` / `role="radio"`, 결과는 `role="status"`로 읽힘.

## 6. 힌트 사다리 (`s6_hints`)
- 사다리 3칸: 1 방향 힌트 → 2 구체 힌트 → 3 정답 코드와 풀이.
- 상태 4개 (목업 데스크톱 아래쪽 비교표)
  | 상태 | 1 | 2 | 3 |
  |---|---|---|---|
  | A 안 엶 | 설명 + 주 버튼 "방향 힌트 열기" | 잠김 "앞 힌트 먼저" | 잠김 |
  | B 1 열림 | 내용 (왼쪽 3px `accent`, "열림") | 설명 + 보조 버튼 "구체 힌트 열기" | 잠김 |
  | C 2 열림 | 내용 | 내용 | 설명 + 보조 버튼 "정답 코드와 풀이 열기" |
  | D 3 열림 | 내용 | 내용 | 정답 코드 블록 + 풀이 |
- 버튼은 한 번에 하나씩만 보인다. 3번 버튼은 주 버튼이 아니라 보조 버튼 (정답으로 바로 가도록 끌지 않음).
- 기록: "이 단계 힌트 사용: 2 / 3 · 기록만 하고 평가하지 않습니다". 단계별 `hintsUsed` (0~3) 저장. 홈·진도에는 보여 주지 않는다 (판단처럼 보이지 않게).
- 위치: 데스크톱 실습 오른쪽 패널 안에서 펼침. 모바일 실습 아래 같은 화면에서 펼침. 별도 화면(목업 `s6_hints`)은 상태 설명용.
- 접근성: 열 때 새로 열린 힌트 제목으로 포커스 이동, `aria-live="polite"`.

## 7. 복습 (`s7_review`)
- 머리: "오늘 4개 · 약 6분 · 1 / 4 진행 중".
- 카드 1장씩: 종류 배지 (개념 / ✕ 문제), 출처 "01 micrograd · 단계 4", 질문 `title-2`.
  - 개념 카드: "답 보기" 버튼 → 답 상자 (`paper-sunken`) → "헷갈려요" (보조) / "기억났어요" (주). 아래 "헷갈려요: 1일 뒤 다시 · 기억났어요: 3일 뒤 다시".
  - 문제 카드: 5번과 같은 문제 화면을 복습 모드로 연다.
- 오른쪽(데스크톱) 또는 아래(모바일): "오늘 남은 것" 목록, "다음 복습" 날짜별 개수, 간격 설명 "1일 → 3일 → 7일 → 14일. 헷갈리면 1일로 돌아갑니다."
- 14일 간격에서 기억났어요를 누르면 대기열에서 빠지고 "익힌 것" 수만 셈 (화면에는 표시 안 함, 1차 범위 밖).
- 빈 상태: "오늘 복습할 것이 없습니다." + 다음 복습 날짜.

## 8. 사전 기초 진입 (`s8_basics`)
- 머리: kicker "강의 전에", 제목 "사전 기초: 파이썬·수학 최소", 설명 "코드를 쓰는 법이 아니라 읽는 법부터 익힙니다."
- 건너뛰기 카드: "이미 아는 내용이면 건너뛰어도 됩니다." 주 버튼 "5문제로 확인하기", 글자 버튼 "건너뛰고 강의 01로".
- 모듈 목록 2개 (파이썬 읽기 6, 수학 감 잡기 4), 각 행 번호, 이름, 예상 분, 상태 (✓ 완료 / ● 지금 / ○ 아직).
- 목업의 모듈 이름은 예시다. 교사 몽키 pedagogy/ 설계로 바꾼다.
- 각 모듈 안 화면은 3·4·5번 틀을 그대로 쓴다 (영상 칸 없음).

## 9. 빈·불러오는 중·오류 (`s9_states`)
| 상황 | 문구 | 동작 |
|---|---|---|
| 처음 연 날 | "어디서부터 시작할까요?" / "코드를 처음 본다면 사전 기초부터, 파이썬을 조금 읽을 수 있다면 강의 01부터 시작하세요." | 주 버튼 "사전 기초부터", 보조 "강의 01 micrograd부터". 숫자는 0과 "–" |
| 복습 없음 | "오늘 복습할 것이 없습니다." / "확인 문제를 풀면 틀린 문제와 핵심 개념이 여기에 모입니다." | |
| 불러오는 중 | "진도를 불러오는 중입니다" + 회색 막대 (움직이지 않음) | 0.3초 안에 끝나면 안 보여 줌. `aria-busy` |
| 저장 실패 | "✕ 진도를 저장하지 못했습니다" / "인터넷 연결을 확인한 뒤 다시 시도해 주세요. 지금까지 한 내용은 이 기기에 남아 있습니다." | 주 버튼 "다시 저장". 로컬에 먼저 저장 후 서버 동기화 |
| 비교 입력 비어 있음 | "✕ 비교할 결과가 비어 있습니다" / "노트북에서 실행한 뒤 출력 칸의 글자를 복사해 붙여 넣어 주세요." | |
| 영상 불러오는 중·오류·접힘 | 0.5 참고 | |

## 10. 접근성 점검표
- 대비: `tokens.md` 3절 표, 모두 AA.
- 누르는 곳 최소 44×44 (목업 18장 자동 검사 통과: 버튼, 칩, 탭, 목록 행, 선택지).
- 의미를 색만으로 전하지 않음: ✓/✕ 아이콘 + 맞음/다시 글자, ● 지금 / ○ 아직 / ✓ 완료, ▲/▼ 변화.
- 포커스 링: `accent` 3px, 2px 띄움. 모든 버튼·링크·줄 버튼.
- `lang="ko"`, 제목 계층 h1 → h2, 랜드마크 (`header`, `main`, `nav`, `aside`).
- `prefers-reduced-motion`: 전환 효과 0ms.
- 확대 200%에서 가로 스크롤 없음 (실습 2단은 1024 미만에서 1단으로 바뀜).
- 영상 iframe에 `title`. 자동 재생 없음.
