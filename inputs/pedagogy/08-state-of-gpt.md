## 1. 학습 목표

1. GPT 비서(ChatGPT 같은) 모델을 만드는 4단계(사전학습, 지도 미세조정, 보상 모델링, 강화학습)를 순서대로 말하고, 단계마다 데이터와 결과물을 짝지을 수 있습니다.

**L08-S04 (선택 실습) 기본 모델 직접 보기**
- 입력: 10편에서 쓸 GPT-2 124M 공개 가중치를 Hugging Face `transformers`로 불러와 영어 질문·답 형식("Q: ... A:")으로 이어 쓰기. GPT-2는 영어 위주로 배운 모델이라 영어로 해 봅니다.
  ```python
  from transformers import pipeline                # Hugging Face 도구에서 파이프라인 불러오기
  gen = pipeline("text-generation", model="gpt2")  # 공개된 GPT-2 작은 모델(124M) 준비
  print(gen("Q: What is the capital of France?\nA:", max_new_tokens=20)[0]["generated_text"])  # 이어 쓰게 하기
  ```
- 보여야 하는 것: 그럴듯하거나 엉뚱하게 이어 쓴 영어 문장.
- 뜻: 비서 훈련이 없어도 "문서 모양"만 잘 주면 답처럼 이어 씁니다. 다만 신뢰할 수는 없습니다.

**L08-S06 프롬프트 요령 묶음표**
- 할 것: 강연에 나오는 요령을 "왜 통하나"와 짝짓기.

| 요령 | 왜 통하나(교사 몽키 정리) |
|---|---|
| 단계별로 생각하게 하기 | 계산을 여러 토큰에 나눠 쓰게 됨 |
| 여러 번 뽑고 고르기 | 한 번 잘못 뽑은 토큰을 스스로 되돌리지 못하므로 |
| 스스로 검토하게 하기 | 모델이 틀렸음을 알아챌 수 있는 경우가 있음 |
| 출력 형식을 정해 주기(제약된 프롬프팅) | 원하는 모양에서 벗어나는 토큰을 막음 |
| 계산기·코드·검색 같은 도구 | 모델이 약한 일(정확한 계산, 최신 정보)을 맡김 |
| 관련 문서를 넣어 주기(검색 증강) | 작업 기억(문맥 창)에 근거를 올려 둠 |
| 잘하는 사람처럼 역할 주기 | 학습 데이터에는 잘한 답과 못한 답이 섞여 있음 |

- 보여야 하는 것: 7개 모두 짝을 맞춤.
- 뜻: 요령은 모두 "모델의 작동 방식"에서 나옵니다.
