작성: 교사 몽키, 2026-11-16 KST. 근거: 얼큰이님 지시(2026-11-16 20:06 KST, CEO 몽키 전달) "Z2H를 일반인 대상 상품으로, 마케팅 메시지를 설계 중심에". 이 파일은 기존 pedagogy 문서를 **배우는 사람이 얻는 것** 기준으로 다시 묶은 안내입니다. 단계, 문제, 익힘 기준 자체는 바꾸지 않고 기존 파일을 가리킵니다.

학습자는 언제든 전체 길로 바꿀 수 있고, 건너뛴 편과 점검을 마치면 전체 배지를 받습니다.

편 도장: 단계 배지와 별도로, 각 편을 익힐 때마다 그 편 이름의 도장을 줍니다(조건 = 그 편 6절). 편 도장에 붙는 선택 공유 결과물은 편 파일 6절에 적습니다(현재 01편: '내 micrograd 학습 기록 카드' `ART-L01`, 01-micrograd.md 6-1절). 맛보기 공유 카드는 `ART-TASTER`(taster.md 4절)입니다. 4절의 짧은 경로를 고른 사람도 도장은 받을 수 있지만, 단계 배지는 그 단계의 모든 편과 점검을 마쳐야 받습니다.

공유 원칙(개인정보와 안전):
- 공유 대상은 **모델이 만든 결과물과 학습 숫자**(이름, 생성 글, 그래프, 손실 값)만입니다. 이메일, 실명, 기기 정보, 학습 시간 기록 같은 개인 정보는 공유 카드에 넣지 않습니다.
- 토크나이저 그림에 쓸 "내 문장"은 앱이 예문을 기본으로 채우고, 직접 입력할 때는 "이름, 주소, 전화번호 같은 개인 정보는 넣지 마세요"를 보여 줍니다.
- 생성된 이름이 우연히 실제 사람 이름과 같을 수 있다는 안내를 공유 카드에 한 줄 넣습니다.
- **자동 게시는 없습니다.** 공유는 늘 학습자가 시작합니다. 공유 화면에는 이미지 저장, 글 복사, 'X에 공유' 단추가 있습니다. 'X에 공유'는 X의 글쓰기 창을 미리 채운 글과 함께 열기만 하고, 게시는 학습자가 직접 누릅니다. 이미지는 자동으로 붙지 않으므로 단추 옆에 '저장한 이미지를 첨부해 주세요'를 보여 줍니다(디자이너·CEO 결정 2026-11-16 20:34 KST). 다른 곳에 올릴 때는 저장한 이미지나 복사한 글을 학습자가 직접 올립니다. 미리 채우는 글에도 모델 결과물과 출처 표기만 넣고 개인 정보는 넣지 않습니다.
- 공유 카드에는 "Andrej Karpathy의 공개 강의를 따라 만든 결과"라는 출처 표기를 넣되, 본인이나 강의 저자가 이 앱을 보증하는 것처럼 보이는 문구와 로고는 넣지 않습니다.

## 4. 대상별 길(페르소나)

시간은 README 3절의 편별 예상 시간(영상의 약 3~5배)을 더한 값입니다. "핵심"은 꼭 권하는 편, "선택"은 관심에 따라 보는 편입니다. 순서는 늘 번호 순서를 지키되(앞 편이 선행 지식), 선택 편은 건너뛸 수 있게 둡니다.

### 4-1. AI를 업무에 쓰는 회사원

- 동기: ChatGPT 같은 도구를 매일 쓰는데, 왜 가끔 엉뚱하게 답하는지, 어떻게 물어야 잘 되는지 근거를 알고 싶습니다.
- 얻는 것: AI는 다음 토큰을 확률로 고르는 모델이라는 감각, 비서 모델이 만들어지는 4단계, 토큰 때문에 생기는 약점(철자, 산수, 한국어 비용), 질문 요령이 통하는 이유.
- 추천 길: 맛보기 → 00 → 01(핵심) → 02(핵심) → 다리 카드(bridge-cards-03-04.md) → 07(핵심, 축소 설정까지) → 08(강력 추천, 핵심) → 09(핵심) / 03~06, 10은 선택.
- 시간: 약 40~60시간. 주 4시간이면 약 3~4개월.
- 받을 수 있는 것: 첫 셀 완주 배지, 편 도장 5개(01, 02, 07, 08, 09), 언어 모델 견습(요약 경로), AI 속 들여다보기 수료(2절 요약 경로 표). 전체 단계 배지는 전체 길로 바꿔 건너뛴 편과 점검을 마쳐야 합니다.
- 07편 준비: 07편은 03·04편 내용(임베딩, 미니배치, 학습률, 데이터 나누기, 초기화, 정규화, 잔차)을 선행 지식으로 씁니다. 이 길에서는 03·04편 대신 **다리 카드 10장**(`bridge-cards-03-04.md`, 약 1~1.5시간)을 02편 뒤, 07편 앞에 봅니다. 시간 합계에 이미 들어 있습니다.
- 메시지 한 줄: "매일 쓰는 AI, 속을 한 번 직접 만들어 보면 쓰는 법이 달라집니다."

### 4-2. AI 산업을 판단해야 하는 투자자·경영자

- 동기: AI 회사 발표의 파라미터 수, 토큰 수, GPU, 벤치마크 같은 숫자가 무엇을 뜻하는지 직접 판단하고 싶습니다.
- 얻는 것: 학습 계산의 대부분이 사전학습에 든다는 구조(08), 모델 크기와 데이터·학습 시간의 관계, 검증 손실과 HellaSwag 같은 평가 숫자 읽기, 원본 규모 재현에 왜 GPU 8장이 필요한지(10 0절).
