## 1. 학습 목표

1. 앞 글자 여러 개(문맥 크기 block_size)를 보고 다음 글자를 맞히는 데이터(X, Y)를 만들 수 있습니다.
2. 임베딩(embedding, 글자 번호마다 배운 숫자 벡터를 붙이는 표) `C[X]`의 모양을 예측하고 설명할 수 있습니다.
3. 임베딩 → 은닉층(tanh) → 출력층 → 교차 엔트로피(cross entropy, 2편 손실을 한 줄로 해 주는 함수) MLP를 직접 만들고 학습시킬 수 있습니다.
4. 미니배치(minibatch, 전체 대신 무작위 일부로 기울기 추정)와 학습률 찾기, 학습률 줄이기(decay)를 쓸 수 있습니다.
5. train/dev/test(학습/검증/시험) 분리로 과소적합·과적합을 판단할 수 있습니다.
6. 2차원 임베딩 그림을 보고 비슷한 글자끼리 모이는 현상을 설명할 수 있습니다.

## 2. 선행 지식

- 반드시: 02편, F-P9(인덱싱, view), F-M3(행렬곱 모양), F-M4
- 있으면 좋음: F-M5

**L03-S01 문맥 데이터 만들기**
- 입력: `block_size = 3`, 각 이름에 대해 `context = [0]*block_size`로 시작해 글자마다 X에 context, Y에 다음 글자를 넣고 context를 한 칸 밀기. 처음엔 5개 이름만.
- 보여야 하는 것: `...` → e, `..e` → m, `.em` → m, `emm` → a, `mma` → `.`
- 뜻: 앞 3글자로 다음 1글자를 맞히는 문제입니다.

**L03-S02 임베딩 표**
- 입력: `C = torch.randn((27, 2))`, `emb = C[X]`, `emb.shape`.
- 보여야 하는 것: [예시 수, 3, 2]
- 뜻: 글자 번호마다 숫자 2개짜리 좌표가 붙습니다. 3글자라 3개씩.

**L03-S03 은닉층**
- 입력: `W1 = torch.randn((6, 100))`, `b1 = torch.randn(100)`, `h = torch.tanh(emb.view(-1, 6) @ W1 + b1)`.
- 보여야 하는 것: `h.shape` [예시 수, 100]
- 뜻: `view(-1, 6)`은 3×2를 6개 한 줄로 펴는 것입니다(-1은 "알아서 맞춰"). `torch.cat`으로 붙이는 것보다 효율적입니다.

**L03-S04 출력층과 손실**
- 입력: `W2 = torch.randn((100, 27))`, `b2 = torch.randn(27)`, `logits = h @ W2 + b2`, 2편 방식 손실과 `F.cross_entropy(logits, Y)` 비교.
- 보여야 하는 것: 두 손실이 같음.
- 뜻: cross_entropy는 같은 계산을 더 빠르고 안전하게(큰 숫자에서도 넘치지 않게) 합니다.

**L03-S05 전체 데이터와 학습 반복**
- 입력: 전체 이름으로 X, Y. 파라미터 리스트에 `requires_grad = True`. 순전파, `p.grad = None`, `loss.backward()`, `p.data += -0.1 * p.grad`.
- 보여야 하는 것: 손실이 내려가지만 한 번 반복이 느림.
- 뜻: 22만 개 전체로 매번 계산하면 느립니다.

**L03-S06 미니배치**
- 입력: `ix = torch.randint(0, X.shape[0], (32,))` 로 32개만 골라 순전파.
- 보여야 하는 것: 반복이 훨씬 빠르고 손실은 덜 매끄럽게 내려감.
- 뜻: 정확한 기울기 대신 대략적인 기울기로 많이 걷는 쪽이 낫습니다.

**L03-S07 학습률 찾기**
- 입력: `lre = torch.linspace(-3, 0, 1000); lrs = 10**lre`, 반복마다 다른 학습률로 한 걸음, 학습률과 손실을 그래프로.
- 보여야 하는 것: 어느 구간에서 손실이 가장 잘 내려가고 그 뒤로 튀는 모양.
- 뜻: 대략 0.1 근처가 좋은 학습률이라고 고릅니다.

**L03-S08 train/dev/test 나누기**
- 입력: 이름을 섞은 뒤 80%/10%/10%로 나눠 Xtr, Xdev, Xte.
- 보여야 하는 것: 세 묶음 크기.
- 뜻: 학습은 train만, 설정 고르기는 dev로, 마지막 확인만 test로 합니다. test는 거의 보지 않습니다.

**L03-S09 과소적합 확인과 모델 키우기**
- 입력: train 손실과 dev 손실 비교 후 은닉 뉴런 300, 임베딩 10차원 등으로 바꿔 다시 학습. 학습률을 중간에 0.01로 줄이기.
- 보여야 하는 것: 두 손실이 비슷하면 아직 모델이 작은 것(과소적합). 키우면 둘 다 더 내려감.
- 뜻: train만 낮고 dev가 높으면 과적합(외워 버림)입니다.

**L03-S10 임베딩 그림**
- 입력: 2차원 C일 때 `plt.scatter(C[:,0], C[:,1])` 와 글자 이름 표시.
- 보여야 하는 것: 모음(a, e, i, o, u)이 서로 가까이 모이는 경향.
- 뜻: 모델이 스스로 "비슷하게 쓰이는 글자"를 가까이 놓았습니다.

**L03-S11 이름 생성**
- 입력: context를 `[0]*block_size`로 시작해 임베딩 → 은닉층 → softmax → 뽑기 반복.
- 보여야 하는 것: 2편보다 훨씬 이름다운 결과.
- 뜻: 앞 3글자를 보니 좋아졌습니다.

- 손실이 inf나 nan으로 나옴(댓글), 손실 그래프의 `stepi` 초기화 빠뜨림(댓글).
