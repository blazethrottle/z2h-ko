## F-P2 변수, 숫자, 글자

**목표**: 변수(값에 붙이는 이름표)를 만들고, 숫자 계산과 글자(문자열) 다루기를 할 수 있습니다.

**따라 하기**
```python
x = 3            # x라는 이름표에 숫자 3을 붙입니다
y = 2.5          # 소수도 됩니다(float, 소수점 숫자)
print(x + y)     # 5.5가 보입니다
x = x + 1        # 지금 x(3)에 1을 더한 값을 다시 x에 붙입니다. 이제 x는 4
print(x)         # 4
s = "emma"       # 따옴표 안은 글자(문자열, string)
print(len(s))    # len: 길이. 4
print(s[0])      # 0번째 글자. 파이썬은 0부터 셉니다. 'e'
```

보여야 하는 것: 5.5, 4, 4, e, 16. 뜻: `=`는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 붙인다"입니다.

**확인 문제**
1. [예측] `a = 5; a = a * 2; print(a)` 정답: 10.

3. [버그] `print(len(emma))`가 에러입니다. 왜? 정답: 따옴표가 없어 emma를 변수 이름으로 봅니다. `len("emma")`로 고칩니다.

## F-P3 리스트와 딕셔너리

**목표**: 여러 값을 담는 리스트(순서 있는 목록)와 딕셔너리(이름표 → 값 사전)를 만들고 꺼낼 수 있습니다.

**따라 하기**
```python
words = ["emma", "olivia", "ava"]   # 대괄호: 리스트
print(words[1])                      # 1번째: olivia
print(words[-1])                     # -1: 맨 끝. ava
print(words[0:2])                    # 0번부터 2번 앞까지(슬라이싱): ['emma', 'olivia']
words.append("mia")                  # 맨 뒤에 추가
print(len(words))                    # 4
stoi = {"a": 1, "b": 2}              # 중괄호: 딕셔너리. 'a'를 1로 바꾸는 사전
print(stoi["b"])                     # 2
stoi["c"] = 3                        # 새 항목 추가
print(sorted(set("hello")))          # set: 중복 제거, sorted: 정렬. ['e','h','l','o']
```
뜻: 2편의 `stoi`(글자→숫자 사전)와 `itos`(숫자→글자 사전)가 바로 이 딕셔너리입니다.

보충(research/09 3절 반영): 튜플(tuple, 바꿀 수 없는 짝 묶음)은 소괄호로 씁니다. `pair = (101, 32)`. 사전의 이름표로 쓸 수 있어 9편에서 `counts[(101, 32)]`처럼 "글자 쌍 → 횟수"를 셉니다. 바이트(bytes)는 0~255 숫자 묶음으로, `"hi".encode("utf-8")`처럼 글자에서 만듭니다(9편 S02).

**확인 문제**
1. [예측] `[10, 20, 30][1:]` 정답: `[20, 30]`.
2. [설명] `stoi`와 `itos`는 서로 어떤 관계인가요? 정답: 방향만 반대인 사전입니다. 글자를 숫자로, 숫자를 글자로.
3. [버그] `d = {"a": 1}; print(d["z"])` 에러(KeyError)의 이유? 정답: 사전에 "z"라는 이름표가 없습니다.

**익힘 기준**: 3개 정답 + 알파벳 'a'~'e'를 1~5로 바꾸는 사전을 힌트 1단계 이하로 만들면 통과.

## F-P4 반복문과 조건문

**목표**: 같은 일을 여러 번 하는 반복문(for)과 조건에 따라 갈리는 조건문(if)을 읽고 쓸 수 있습니다.

**따라 하기**
```python
for w in ["emma", "ava"]:      # 리스트에서 하나씩 꺼내 w라고 부르며 반복
    print(w, len(w))            # 들여쓰기(앞 공백 4칸)가 "반복 안쪽"이라는 표시
for i in range(3):              # range(3): 0, 1, 2
    print(i)
for a, b in zip("emma", "mma"): # zip: 두 줄을 나란히 짝지어 꺼냄. (e,m) (m,m) (m,a)
    print(a, b)
x = 5
if x > 3:                       # 조건이 참이면
    print("크다")
else:                           # 아니면
    print("작다")
```
보충(research/09 3절 반영): `while 조건:`은 조건이 참인 동안 계속 반복합니다. 9편 encode는 "합칠 쌍이 남아 있는 동안" 반복합니다.
```python
n = 3              # 3에서 시작
while n > 0:       # n이 0보다 큰 동안
    print(n)       # 3, 2, 1
    n = n - 1      # 하나씩 줄이기. 이 줄이 없으면 끝나지 않습니다
```

뜻: 2편의 "글자 쌍 세기"는 `zip`으로 이웃한 두 글자를 짝짓는 반복입니다. 들여쓰기가 틀리면 IndentationError가 납니다.

**확인 문제**
1. [예측] `for i in range(2, 5): print(i)` 정답: 2, 3, 4.
2. [예측] `list(zip("ab", "bc"))` 정답: `[('a','b'), ('b','c')]`.
3. [버그] 반복 안쪽 줄이 들여쓰기 없이 쓰여 에러가 납니다. 고치는 법? 정답: 안쪽 줄 앞에 공백 4칸.

**익힘 기준**: 3개 정답 + "단어 리스트에서 길이가 4 이상인 것만 출력"을 힌트 2단계 이하로 작성하면 통과.

## F-P5 함수

**목표**: 함수(입력을 받아 일을 하고 결과를 돌려주는 묶음)를 만들고 부를 수 있습니다.

**따라 하기**
```python
def f(x):                  # def: 함수 만들기. 이름은 f, 입력은 x
    return 3*x**2 - 4*x + 5   # return: 결과를 돌려줌
print(f(3.0))              # 20.0
def add(a, b=1):           # b=1: 안 주면 1을 씀(기본값)
    return a + b
print(add(2), add(2, 5))   # 3 7
g = lambda x: x * 2        # lambda: 한 줄짜리 이름 없는 함수
print(g(4))                # 8
```
뜻: `f(x) = 3x² - 4x + 5`는 1편 맨 처음에 나오는 바로 그 함수입니다.

보충(research/09 3절 반영): `max(stats, key=stats.get)`은 "사전에서 값이 가장 큰 이름표"를 고릅니다. `key=`에 넣은 함수로 비교 기준을 정하는 방법이며, 9편 BPE에서 가장 흔한 쌍을 찾을 때 씁니다.
```python
stats = {("a","b"): 5, ("b","c"): 2}   # 쌍 → 횟수
print(max(stats, key=stats.get))          # 값이 가장 큰 쌍: ('a', 'b')
```

**확인 문제**
1. [예측] `f(0)` 정답: 5.
2. [설명] `return`이 없으면 함수는 무엇을 돌려주나요? 정답: None(아무것도 없음).
3. [버그] `def sq(x): x*x` 를 `print(sq(3))`하면 None이 나옵니다. 정답: `return x*x`로 고칩니다.

**익힘 기준**: 3개 정답 + 두 수의 평균을 돌려주는 함수를 힌트 1단계 이하로 작성하면 통과.

## F-P6 클래스와 객체(특수 메서드 포함)

**목표**: 클래스(물건의 설계도)로 객체(실제 물건)를 만들고, `__init__`, `__repr__`, `__add__`, `__call__` 같은 특수 메서드가 언제 불리는지 설명할 수 있습니다. 1편 micrograd의 `Value`가 바로 이것입니다.

**따라 하기**
```python
class Box:                          # Box라는 설계도
    def __init__(self, data):       # 만들 때 자동으로 불림. self는 "이 물건 자신"
        self.data = data            # 물건 안에 data라는 칸을 만들어 값을 넣음
    def __repr__(self):             # print할 때 어떻게 보일지
        return f"Box({self.data})"  # f"...{}...": 중괄호 안 값을 글자에 끼워 넣기
    def __add__(self, other):       # a + b 를 쓰면 a.__add__(b)가 불림
        return Box(self.data + other.data)
    def __call__(self, x):          # 물건을 함수처럼 b(x)로 부를 때
        return self.data * x
a = Box(2); b = Box(3)
print(a + b)                        # Box(5)
print(a(10))                        # 20
```
뜻: `+`를 썼는데 실제로는 `__add__`가 실행됩니다. micrograd는 이 원리로 계산을 기록합니다. 4·6편의 `Linear`, `BatchNorm1d`와 7·10편의 `nn.Module`도 `__call__`로 "층을 함수처럼 부르기"를 합니다.

**확인 문제**
1. [예측] 위 코드에서 `print(Box(1) + Box(1) + Box(1))` 정답: `Box(3)`.
2. [설명] `self`는 무엇인가요? 정답: 메서드가 지금 다루는 그 객체 자신입니다.
3. [버그] `a * b`를 했더니 TypeError. 정답: `__mul__`을 만들지 않아서입니다.

**익힘 기준**: 3개 정답 + Box에 `__mul__`을 힌트 2단계 이하로 추가하면 통과.

## F-P7 에러 메시지 읽기

**목표**: 에러 메시지의 맨 아래 줄(에러 종류와 이유)과 화살표가 가리키는 줄을 찾아 원인을 짐작할 수 있습니다.

**따라 하기**
1. `print(undefined_name)` 실행 → `NameError: name 'undefined_name' is not defined`. 뜻: 그런 이름표가 없습니다.
2. `[1,2][5]` 실행 → `IndexError: list index out of range`. 뜻: 목록 범위를 벗어났습니다.
3. `"a" + 1` 실행 → `TypeError`. 뜻: 글자와 숫자는 더할 수 없습니다.
4. (F-P9 뒤) `torch.zeros(2,3) @ torch.zeros(2,3)` → `RuntimeError: mat1 and mat2 shapes cannot be multiplied`. 뜻: 행렬 모양이 맞지 않습니다. 강의 전체에서 가장 자주 보게 될 에러입니다.

읽는 순서(앱 고정 안내): ① 맨 아래 줄의 에러 종류 ② 그 줄의 설명 ③ 위로 올라가 내 셀의 몇째 줄인지(`---->` 표시) ④ 그 줄의 변수 값을 print로 확인.

**확인 문제**
1. [설명] NameError가 나면 가장 먼저 무엇을 확인하나요? 정답: 철자, 그리고 그 변수를 만드는 셀을 먼저 실행했는지.
2. [설명] 모양 에러가 나면 무엇을 print하나요? 정답: 관련 텐서들의 `.shape`.
3. [버그] `for i in range(3) print(i)` 의 SyntaxError 원인? 정답: 콜론(:)과 줄바꿈·들여쓰기가 빠졌습니다.

**익힘 기준**: 에러 4종(Name, Index, Type, 모양) 예시를 보고 원인을 말로 설명하기 4개 중 4개.

## F-P8 numpy 배열 기초

**목표**: numpy(숫자 목록을 한꺼번에 계산하는 도구)로 배열을 만들고 한 번에 계산하며, 그래프를 그릴 수 있습니다.

**따라 하기**
```python
import numpy as np                 # numpy를 np라는 짧은 이름으로 불러옴
import matplotlib.pyplot as plt    # 그래프 도구
xs = np.arange(-5, 5, 0.25)        # -5부터 5 앞까지 0.25 간격 숫자들
ys = 3*xs**2 - 4*xs + 5            # 배열 전체에 한 번에 계산(반복문 없이)
print(xs.shape)                    # 모양: (40,)  40개짜리 한 줄
plt.plot(xs, ys)                   # 선 그래프
```
보여야 하는 것: 아래로 볼록한 포물선 그래프. 뜻: 1편 첫 장면을 그대로 미리 해 본 것입니다.

**확인 문제**
1. [예측] `np.array([1,2,3]) * 2` 정답: `[2 4 6]`.
2. [설명] 반복문 없이 배열 전체를 계산하는 장점? 정답: 짧고 빠릅니다.
3. [예측] `np.arange(0, 1, 0.5)` 정답: `[0. 0.5]`.

**익힘 기준**: 3개 정답 + y = x³ 그래프를 힌트 1단계 이하로 그리면 통과.

## F-P9 torch 텐서 기초

**목표**: 텐서(torch의 다차원 숫자 상자)의 모양(shape)을 읽고, 인덱싱, 합(sum), 브로드캐스팅(작은 텐서를 자동으로 늘려 계산), 장치 선택을 할 수 있습니다.

**따라 하기**
```python
import torch                          # PyTorch 불러오기
N = torch.zeros((3, 4), dtype=torch.int32)  # 3행 4열, 모두 0인 정수 텐서
print(N.shape)                        # torch.Size([3, 4])
N[1, 2] += 1                          # 1행 2열에 1 더하기
print(N[1])                           # 1행 전체: tensor([0, 0, 1, 0])
P = torch.ones(3, 4)                  # 모두 1
print(P.sum(1, keepdim=True).shape)   # 1번 축(가로)으로 합, 축 유지: [3, 1]
print(P.sum(1).shape)                 # 축 유지 안 함: [3]
Q = P / P.sum(1, keepdim=True)        # [3,4] / [3,1] → [3,1]이 가로로 늘어나 나눠짐
print(Q[0])                           # tensor([0.25, 0.25, 0.25, 0.25])
x = torch.randn(2, 3)                 # 정규분포 무작위 수
W = torch.randn(3, 5)
print((x @ W).shape)                  # @: 행렬곱. [2,3]@[3,5] → [2,5]
dev = "mps" if torch.backends.mps.is_available() else ("cuda" if torch.cuda.is_available() else "cpu")
print(dev)                            # 맥미니는 mps, Colab GPU는 cuda, 아니면 cpu
```
뜻: `keepdim`을 빼먹으면 모양이 달라져 조용히 틀린 결과가 나올 수 있습니다. 이것이 2편에서 Karpathy가 강조하는 브로드캐스팅 함정입니다.

**확인 문제**
1. [예측] `torch.zeros(27, 27)[0].shape` 정답: `torch.Size([27])`.
2. [예측] `[32, 3] @ [3, 100]`의 결과 모양 정답: `[32, 100]`.
3. [설명] 브로드캐스팅을 쉬운 말로. 정답: 모양이 1인 축을 자동으로 복사해 늘려서 계산하는 규칙.
4. [버그] 행마다 합이 1이 되게 하려고 `P / P.sum(1)`을 썼는데 결과가 이상합니다. 정답: `keepdim=True`가 빠져 [3]이 세로가 아닌 가로 방향으로 늘어났습니다.

**익힘 기준**: 4문제 중 4개(특히 4번) 정답 + 모양 맞히기 5문항 중 4개 이상.

## F-M1 미분 = 기울기

**목표**: 미분(derivative)을 "입력을 아주 조금 바꿨을 때 출력이 얼마나 바뀌는지의 비율"로 설명하고, 숫자로 직접 계산할 수 있습니다.

**따라 하기**
```python
def f(x): return 3*x**2 - 4*x + 5   # 함수
h = 0.0001                           # 아주 작은 변화량
x = 3.0
print((f(x + h) - f(x)) / h)         # 기울기 근사: 약 14.0003
x = 2/3
print((f(x + h) - f(x)) / h)         # 약 0 (그래프의 바닥)
```
뜻: 수식으로 미분하면 6x - 4 이고, x=3이면 14입니다. 기울기가 0인 곳은 그래프가 평평한 곳(최솟값)입니다.

**확인 문제**
1. [예측] x = -1일 때 기울기의 부호는? 정답: 음수(-10). 오른쪽으로 가면 내려갑니다.
2. [설명] h를 0.0001처럼 작게 하는 이유? 정답: 그 점 바로 근처의 기울기만 보려고.
3. [설명] `d = a*b + c`에서 a를 조금 올리면 d는 얼마나 변하나요? 정답: b만큼의 비율로 변합니다(d를 a로 미분하면 b).

**익힘 기준**: 3개 정답 + 임의의 x에서 숫자 기울기를 직접 계산하기.

## F-M2 연쇄 법칙 감각

**목표**: 연쇄 법칙(chain rule, 단계를 거쳐 영향을 줄 때 기울기끼리 곱한다)을 예로 설명할 수 있습니다. 역전파(backpropagation, 결과에서 거꾸로 기울기를 전하는 계산)의 핵심입니다.

**따라 하기**
- 예: 자전거가 걷기보다 2배 빠르고, 자동차가 자전거보다 4배 빠르면, 자동차는 걷기보다 2 × 4 = 8배 빠릅니다.
- 계산: `e = a * b`, `L = e + c`. L을 e로 미분하면 1, e를 a로 미분하면 b. 그래서 L을 a로 미분하면 1 × b = b.
- 숫자 확인: 
  ```python
  a, b, c = 2.0, -3.0, 10.0          # 세 값
  L1 = a*b + c                        # 원래 L
  L2 = (a+0.0001)*b + c               # a만 살짝 올린 L
  print((L2 - L1)/0.0001)             # 약 -3.0 = b
  ```

**확인 문제**
1. [설명] `+` 노드는 들어온 기울기를 어떻게 전하나요? 정답: 양쪽에 그대로(1을 곱해서) 나눠 줍니다.
2. [설명] `*` 노드는? 정답: 상대편 값을 곱해서 전합니다.
3. [예측] `L = (a*b)*f`에서 L을 a로 미분하면? 정답: b*f.

**익힘 기준**: 3개 정답 + 4개 노드짜리 계산 그림에서 모든 기울기를 손으로 채우기(힌트 2단계 이하).

## F-M3 벡터, 행렬, 행렬곱

**목표**: 벡터(숫자 한 줄), 행렬(숫자 표)의 모양을 말하고, 행렬곱의 모양 규칙 [a,b]@[b,c] → [a,c] 를 쓸 수 있습니다.

**따라 하기**
```python
import torch
x = torch.tensor([1., 2., 3.])         # 벡터, 모양 [3]
W = torch.tensor([[1., 0.], [0., 1.], [1., 1.]])  # 행렬, 모양 [3, 2]
print(x @ W)                            # [1*1+2*0+3*1, 1*0+2*1+3*1] = [4., 5.]
print(W.T.shape)                        # .T: 전치(가로세로 뒤집기) [2, 3]
```
뜻: 한 출력 칸은 "입력 한 줄과 가중치 한 열을 칸끼리 곱해서 더한 값"입니다. 신경망의 한 층(Linear)은 이 계산 하나입니다.

**확인 문제**
1. [예측] `[4, 27] @ [27, 27]`의 모양 정답: `[4, 27]`.
2. [예측] `[2,3] @ [2,3]`은? 정답: 에러. 가운데 숫자(3과 2)가 같아야 합니다.
3. [설명] 원-핫(one-hot) 벡터 @ 행렬은 무엇과 같나요? 정답: 그 행렬의 한 행을 꺼내는 것과 같습니다(2·3편 임베딩의 원리).

**익힘 기준**: 모양 문제 6개 중 5개 이상 + 2×2 행렬곱을 손으로 1개 계산.

## F-M4 확률, softmax, log

**목표**: 확률 분포(합이 1인 숫자들), softmax(아무 숫자들을 확률로 바꾸는 계산), log(곱을 합으로 바꾸는 함수)와 음의 로그 가능도(negative log likelihood, 정답에 준 확률이 낮을수록 커지는 벌점)를 설명할 수 있습니다.

**따라 하기**
```python
import torch
logits = torch.tensor([2.0, 1.0, 0.1])   # 로짓: 확률이 되기 전 점수
counts = logits.exp()                     # exp: 양수로 만들기
probs = counts / counts.sum()             # 합으로 나눠 합이 1이 되게: softmax
print(probs, probs.sum())                 # 약 [0.66, 0.24, 0.10], 1.0
print(-torch.log(probs[0]))               # 정답이 0번일 때 벌점: 약 0.42
print(-torch.log(torch.tensor(1/27)))     # 27개 중 아무거나 고를 때 벌점: 약 3.30
```
뜻: 3.30은 2·3·4편에서 "학습 시작 때 손실이 이 근처여야 정상"이라는 기준으로 다시 나옵니다.

**확인 문제**
1. [예측] 확률 1에 대한 -log 값 정답: 0. 완벽하면 벌점 0.
2. [설명] 확률을 곱하는 대신 log를 더하는 이유? 정답: 작은 확률을 계속 곱하면 0에 가까워져 다루기 어렵고, log 합은 다루기 쉽습니다.
3. [예측] logits에 모두 10을 더해도 softmax 결과는? 정답: 그대로입니다.

**익힘 기준**: 3개 정답 + 3개짜리 점수로 softmax를 직접 코드로 계산.

## F-M5 평균과 분산

**목표**: 평균(가운데 값)과 분산·표준편차(퍼진 정도)를 구하고, "평균 0, 표준편차 1로 맞추기"(정규화)를 할 수 있습니다.

**따라 하기**
```python
import torch
x = torch.randn(1000) * 5 + 3       # 평균 약 3, 표준편차 약 5
print(x.mean(), x.std())            # 약 3, 약 5
z = (x - x.mean()) / x.std()        # 정규화
print(z.mean(), z.std())            # 약 0, 약 1
```
뜻: 4편의 BatchNorm(배치 정규화), 7편의 LayerNorm(층 정규화)이 바로 이 계산입니다.

보충(research/04 3절 반영): 히스토그램(값을 구간별로 세어 막대로 그린 그림) 읽기. `plt.hist(x.tolist(), 50)`을 그리면 가운데가 높은 종 모양(정규분포)이 보입니다. 4편은 이 그림으로 값이 양 끝(-1, 1)에 몰렸는지를 봅니다. 종이 넓으면 분산이 크고, 좁으면 작습니다.

**확인 문제**
1. [예측] [2, 4, 6]의 평균 정답: 4.
2. [설명] 분산이 크다는 뜻? 정답: 값들이 평균에서 멀리 퍼져 있습니다.
3. [설명] 무작위 수에 0.1을 곱하면 표준편차는? 정답: 0.1배가 됩니다.

**익힘 기준**: 3개 정답 + 정규화 코드를 힌트 1단계 이하로 작성.

## F-M6 손실과 경사 하강

**목표**: 손실(loss, 모델이 얼마나 틀렸는지 나타내는 숫자)을 줄이려면 기울기의 반대 방향으로 조금씩 움직인다(경사 하강, gradient descent)는 것을 직접 해 봅니다.

**따라 하기**
```python
def loss(w): return (w - 3)**2     # w=3일 때 손실 0
w = 0.0                             # 시작점
for step in range(20):              # 20번 반복
    grad = 2*(w - 3)                # 기울기
    w = w - 0.1 * grad              # 0.1: 학습률(learning rate, 한 번에 움직이는 크기)
print(w)                            # 3에 가까움
```
뜻: 1편 끝의 학습 반복이 이 구조와 같습니다. 학습률을 1.5로 바꾸면 값이 튀어 오릅니다(직접 해 보기).

**확인 문제**
1. [설명] 왜 기울기에 빼기(-)를 하나요? 정답: 기울기는 손실이 늘어나는 방향이라 반대로 가야 줄어듭니다.
2. [예측] 학습률이 너무 작으면? 정답: 아주 느리게 다가갑니다.
3. [예측] 학습률 1.5에서 w는? 정답: 점점 커지며 발산합니다.

**익힘 기준**: 3개 정답 + 학습률을 바꿔 가며 결과 차이를 자기 말로 설명.
