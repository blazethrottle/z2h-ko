# 복습 설계: 간격 복습과 누적 점검

목적: 한 번 익힌 것을 잊기 전에 짧게 다시 꺼내 봅니다. 하루 복습은 15~25분을 넘기지 않습니다.

## 1. 복습 카드

편이나 기초 단위를 "익혔다"고 판정하면 그 편의 복습 카드가 생깁니다. 카드 한 장 = 한 개념(예: "L01 연쇄 법칙으로 * 노드 기울기 구하기"). 카드 내용은 각 편의 확인 문제와 같은 유형의 새 문항입니다.

카드 종류:
- 개념 카드: 자기 말로 설명하기 1문항.
- 예측 카드: 코드 조각을 보고 결과 맞히기 1문항.
- 손 카드: 핵심 조각 짧게 다시 치기(5~10줄). 7일 차 이후에만 나옵니다.

## 2. 간격 일정

기본 간격: 1일 → 3일 → 7일 → 14일 → 30일 → 졸업(이후 60일마다 1문항).

| 시점 | 무엇을 복습하나 | 분량 |
|---|---|---|
| 1일 뒤 | 그 편 학습 목표마다 개념 카드 1장 + 전날 H3·H4를 쓴 문항 재도전 | 5~8문항 |
| 3일 뒤 | 예측 카드 중심. 전날 틀린 카드 | 4~6문항 |
| 7일 뒤 | 손 카드 1장(핵심 재구성 과제의 가장 중요한 조각) + 개념 카드 | 3~5문항 |
| 14일 뒤 | 앞 편과 섞은 카드(예: L03 카드에 L01 개념 섞기) | 3~5문항 |
| 30일 뒤 | 손 카드 1장 + 그 편 "익혔다" 기준의 핵심 질문 1개 | 2~3문항 |

## 3. 결과에 따라 간격이 바뀌는 규칙

카드마다 결과를 셋으로 나눕니다.

| 결과 | 기준 | 다음 간격 |
|---|---|---|
| 통과 | H0~H1로 정답 | 다음 단계로 진행(예: 3일 → 7일) |
| 흔들림 | H2로 정답, 또는 정답이지만 설명이 채점 기준의 절반만 | 같은 간격 유지(3일 → 다시 3일) |
| 놓침 | 오답, 또는 H3 이상 | 1일로 되돌림 |

추가 규칙:
- 한 편의 카드 중 절반 이상이 "놓침"이면 그 편의 익힘 상태를 "다시 보기"로 바꾸고, 해당 영상 구간과 따라 하기 단계를 다시 안내합니다.
- 하루에 쌓인 복습이 25분 분량을 넘으면 간격이 긴 카드부터 하루씩 미룹니다(가장 최근 것을 먼저).
- 복습을 빼먹은 날은 벌점이 없습니다. 다음 날 밀린 카드 중 가장 오래된 것부터 냅니다.

## 4. 누적 점검 퀴즈

새 편을 열기 전 관문입니다. 통과 기준은 80% 이상, 시간 제한은 없으며 힌트는 H2까지만 쓸 수 있습니다.

### 점검 1: 1~3편 뒤 (4편을 열기 전), 약 1시간
- 개념(6문항): 기울기의 뜻, 연쇄 법칙, 역전파 순서(위상 정렬, 계산 순서의 반대), 바이그램 확률표, 음의 로그 가능도, 임베딩.
- 예측(4문항): `Value` 덧셈 기울기 누적, `keepdim` 유무에 따른 모양, `C[X]`의 모양, 학습 시작 손실이 약 3.3인 이유.
- 손(1과제): 빈 노트북에서 2편의 신경망 바이그램 모델 학습 반복(순전파, 손실, `zero grad`, 역전파, 갱신) 작성. 각 줄에 자기 말 풀이 달기.
- 실패 시: 놓친 개념이 속한 편의 복습 카드를 1일 간격으로 되돌리고, 3일 뒤 다시 봅니다.

### 점검 2: 1~6편 뒤 (7편을 열기 전), 약 1.5시간
- 개념(8문항): 과적합과 train/dev/test 분리, 학습률 찾기, 초기화가 중요한 이유, tanh 포화, BatchNorm이 하는 일과 추론 때의 running 평균, 손으로 한 역전파 결과를 torch와 비교하는 법, 계층적 구조(WaveNet)의 이유, `nn.Module` 같은 층 클래스의 공통 모양.
- 예측(4문항): 활성값 히스토그램 해석, 교차 엔트로피 기울기의 모양, BatchNorm 3차원 입력 버그, `FlattenConsecutive` 뒤 모양.
- 손(1과제): 교차 엔트로피 손실의 역전파(`dlogits`)를 힌트 H2 이하로 다시 작성하고 torch 결과와 비교.

### 점검 3: 1~10편 뒤 (과정 수료), 약 2시간
- 개념(10문항): 자기주의(self-attention)의 질의·키·값, 인과 마스크, 잔차 연결과 정규화, 토큰화(BPE)와 이상한 행동의 관계, GPT 비서 모델 학습 단계(사전학습, 지도 미세조정, 보상 모델, 강화학습), 가중치 공유, 학습률 일정(워밍업과 코사인), 기울기 누적, 혼합 정밀도, 평가(검증 손실, HellaSwag).
- 예측(5문항): 마스크 전후 가중치, 토큰 개수 세기, 모양 추적, 학습률 일정 그래프 읽기, 배치 크기 계산.
- 손(1과제): 작은 GPT 블록(Block: LayerNorm, 자기주의, MLP, 잔차)을 빈 파일에서 H2 이하로 작성하고 축소판 학습을 100스텝 돌려 손실이 내려가는지 확인.
- 통과하면 수료입니다. 수료 뒤 모든 카드는 60일 간격의 유지 복습으로 바뀝니다.

## 5. 기초 모듈(00) 복습

- 기초 단위는 가벼운 일정(3일 → 14일 → 졸업)을 씁니다.
- 강의 중 힌트 H2가 기초 단위(F-xx)를 가리키면 그 단위 카드를 1일 간격으로 되살립니다.
