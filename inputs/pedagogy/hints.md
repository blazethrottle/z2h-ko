# 공통 힌트 사다리

목적: 막혔을 때 바로 정답을 보여 주지 않고, 스스로 풀 수 있는 가장 작은 도움부터 차례로 줍니다. 모든 편, 모든 실습 단계와 확인 문제에 같은 규칙을 씁니다. 편별 예시 힌트는 각 편 파일의 "편별 힌트 예시"에 있습니다.

## 1. 단계

| 단계 | 이름 | 내용 | 예(1편 "a.grad가 0으로 나와요") |
|---|---|---|---|
| H0 | 혼자 풀기 | 힌트 없음 | |
| H1 | 질문으로 찌르기 | 생각할 방향만 질문으로 줍니다. 코드도 개념 이름도 말하지 않습니다 | "backward()를 부른 대상은 어떤 값인가요? 그 값부터 기울기가 시작되나요?" |
| H2 | 개념·줄 가리키기 | 필요한 개념 이름과, 문제가 있는 줄(또는 기초 단위 번호)을 짚습니다 | "출력 노드의 grad를 1.0으로 정했는지 보세요(F-M2 연쇄 법칙). `backward()` 첫 줄입니다" |
| H3 | 빈칸 코드 | 정답 코드에서 핵심 부분만 빈칸(`___`)으로 둔 코드를 줍니다 | `self.grad = ___` 다음에 `for node in reversed(topo): node._backward()` |
| H4 | 정답과 줄별 풀이 | 전체 정답 코드와 줄마다 한국어 풀이를 줍니다 | 정답 코드 + 줄별 표 |
| HELP | 도움 요청 | 앱이 질문 내용(셀 코드, 에러 마지막 줄, 하려던 것)을 자동으로 정리해 도움 요청 메모를 만듭니다 | |

## 2. 언제 열리나

- H1: 언제든 바로 열 수 있습니다.
- H2: H1을 본 뒤 한 번 더 시도(셀 실행 1회 또는 답 제출 1회)하면 열립니다.
- H3: H2를 본 뒤 한 번 더 시도하면 열립니다. 또는 같은 단계에서 15분이 지나면 열립니다.
- H4: H3을 본 뒤 한 번 더 시도하면 열립니다. 또는 같은 단계에서 30분이 지나면 열립니다.
- HELP: H4를 보고도 실행 결과가 "보여야 하는 것"과 다르면 열립니다. 대개 환경 문제(설치, 장치, 버전)입니다.
- 에러 메시지가 났을 때는 H1 대신 "에러 읽기 도우미"(F-P7의 4단계 읽는 순서)를 먼저 보여 줍니다. 이것은 힌트 사용으로 치지 않습니다.
- 예측 문제(실행 전 맞히기)에는 힌트가 없습니다. 틀려도 감점이 아니라 실행 후 설명으로 이어집니다.

## 3. 힌트가 점수와 익힘에 주는 영향

문항(확인 문제 1개 또는 핵심 재구성 과제의 조각 1개)마다 가장 높이 쓴 힌트 단계로 점수를 매깁니다.

| 가장 높이 쓴 단계 | 점수 비율 | 복습 처리 |
|---|---|---|
| H0, H1 | 100% | 보통 일정 |
| H2 | 80% | 보통 일정 |
| H3 | 50% | 다음 복습에 이 문항을 반드시 다시 냄 |
| H4 | 0% (완료는 인정) | 다음 날 같은 유형의 새 문항으로 재도전. 재도전을 H2 이하로 풀면 50%로 회복 |
| HELP | 0% | 환경 문제였다고 확인되면 점수에서 제외(분모에서 뺌) |

익힘 판정 규칙(모든 편 기본값, 편별 파일에서 더 엄하게 정할 수 있음):
- 확인 문제 점수 합 80% 이상.
- 핵심 재구성 과제는 각 조각을 H2 이하로 완성해야 합니다. 한 조각이라도 H3 이상이면 "거의 익힘"으로 두고, 하루 뒤 재구성을 다시 합니다.
- 실습 따라 하기 단계는 점수가 없고 완료 여부만 셉니다. 힌트를 써도 됩니다. 마음 편히 따라 하는 것이 목적입니다.

## 4. 힌트를 쓰는 사람(콘텐츠 제작자)을 위한 규칙

1. H1은 질문 한 문장. 답을 품지 않습니다.
2. H2는 개념 이름 + 위치. 기초 단위 번호(F-xx)나 앞 단계 번호(L0x-Sxx)를 걸어 둡니다.
3. H3의 빈칸은 1~3개. 빈칸 하나에 들어갈 답은 한 덩어리(변수 하나, 식 하나)입니다.
4. H4는 정답 코드 전체 + 줄별 풀이 표 + "왜 내 답이 틀렸을 가능성이 큰가" 한 줄.
5. 모든 힌트는 합니다체, 쉬운 말, 용어는 처음 쓸 때 풀이.
6. 원본 저장소 코드를 길게 붙여 넣지 않습니다. 필요한 몇 줄만 쓰고 원본 위치(저장소 이름, 파일 이름)를 적습니다.

## 5. 도움 요청(HELP) 메모 형식

앱이 자동으로 채우는 칸:
- 편과 단계: 예 L07-S12
- 하려던 것: 단계 제목
- 내 셀 코드: 마지막 실행 셀
- 에러 마지막 줄 또는 "보인 것"
- 환경: 맥미니(MPS)인지 Colab(GPU 종류)인지, torch 버전
- 이미 본 힌트 단계

이 메모는 얼큰이님 화면에만 만들어지고, 누구에게 보낼지는 얼큰이님이 정합니다(외부 발송은 자동으로 하지 않습니다).
