## 1. 학습 목표

이 편을 마치면 얼큰이님은:
1. 숫자 기울기(f(x+h)-f(x))/h 를 계산하고 그 뜻을 말로 설명할 수 있습니다.
2. `+`, `*`, `tanh` 노드에서 기울기가 어떻게 전달되는지(연쇄 법칙) 손으로 채울 수 있습니다.
3. `Value` 클래스가 계산을 기록하고 `backward()`로 거꾸로 기울기를 채우는 과정을 줄별로 설명할 수 있습니다.
4. 같은 값을 두 번 쓰면 기울기를 더해야(`+=`) 하는 이유를 버그 예로 보여 줄 수 있습니다.
5. `Neuron`, `Layer`, `MLP`를 만들고, 손실을 줄이는 학습 반복(순전파, 기울기 0으로 비우기, 역전파, 갱신)을 직접 돌릴 수 있습니다.
6. 같은 계산을 PyTorch로 해서 기울기가 같은지 비교할 수 있습니다.

## 2. 선행 지식

- 반드시: F-P1, F-P2, F-P5, F-P6(특수 메서드), F-P7, F-M1, F-M2, F-M6
- 있으면 좋음: F-P3, F-P4, F-P8(그래프 그리기)

**L01-S02 숫자 기울기**

- 보여야 하는 것: 약 14.
- 뜻: x를 아주 조금 올리면 f는 약 14배로 오릅니다.

**L01-S03 입력이 여러 개일 때 (긴 단계)**
- 새 코드: 약 6줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력: `a=2.0; b=-3.0; c=10.0; d = a*b + c` 를 만들고, a만 h만큼 올린 d2와 비교해 `(d2-d)/h`.
- 보여야 하는 것: 약 -3.0 (b의 값).
- 뜻: d를 a로 미분하면 b. 같은 방법으로 b에 대해서는 2.0, c에 대해서는 1.0이 나오는지 직접 바꿔 봅니다.

**L01-S04 Value 클래스 뼈대 (긴 단계)**
- 새 코드: 약 8줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력:
  ```python
  class Value:                                   # 숫자 하나를 감싸는 상자
      def __init__(self, data, _children=(), _op=''):
          self.data = data                       # 실제 숫자
          self.grad = 0.0                        # 기울기. 처음엔 0
          self._prev = set(_children)            # 나를 만든 재료 값들
          self._op = _op                         # 어떤 계산으로 만들어졌는지('+', '*')
      def __repr__(self):
          return f"Value(data={self.data})"      # 출력 모양
  ```
- 보여야 하는 것: `Value(2.0)`을 실행하면 `Value(data=2.0)`.
- 뜻: 숫자에 "기울기 칸"과 "족보(재료 기록)"를 붙였습니다.

**L01-S05 덧셈과 곱셈 기록하기 (긴 단계)**
- 새 코드: 약 8줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력: `__add__`, `__mul__` 두 메서드를 추가합니다. 결과 `Value`를 만들 때 `(self, other)`를 재료로, `'+'` 또는 `'*'`를 기호로 넘깁니다.
- 보여야 하는 것: `d = a*b + c; d._prev` 가 두 재료 값을, `d._op`가 `'+'`를 보여 줌.
- 뜻: 계산할 때마다 "누가 누구로 만들어졌는지"가 그물(계산 그래프)로 남습니다.

**L01-S06 계산 그래프 그림**
- 새 코드: 1줄 (`draw_dot(d)`). 그림 함수 `draw_dot`(약 25줄)은 **준비 코드**로 붙여 넣기만 합니다(README 원칙 2의 준비 코드 규칙).
- 입력: 원본 노트북(nn-zero-to-hero `lectures/micrograd`)의 `draw_dot` 함수를 준비 코드 셀에 붙여 넣고 `draw_dot(d)` 실행. 준비 코드도 줄마다 풀이를 펼쳐 볼 수 있게 두지만 외울 필요는 없고, 확인 문제나 재구성 과제에도 나오지 않습니다.
- 보여야 하는 것: a, b, c, d가 상자로, 계산 기호가 동그라미로 이어진 그림.
- 뜻: 역전파는 이 그림을 오른쪽에서 왼쪽으로 거슬러 가는 일입니다.

**L01-S07 손으로 기울기 채우기 (긴 단계)**
- 새 코드: 약 8줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력: 그림의 각 노드에 `x.grad = ...`를 손으로 계산해 넣습니다. 맨 끝 L의 grad는 1.0부터.
- 보여야 하는 것: 그림을 다시 그리면 각 상자에 grad 숫자가 보임. S03의 숫자 기울기와 같아야 합니다.
- 뜻: + 노드는 기울기를 그대로 나눠 주고, * 노드는 상대 값을 곱해 줍니다(F-M2).

**L01-S08 한 걸음 움직여 보기 (긴 단계)**
- 새 코드: 약 6줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력: 모든 잎 노드(a, b, c, f)에 `x.data += 0.01 * x.grad` 후 다시 계산.
- 보여야 하는 것: L 값이 조금 커짐.
- 뜻: 기울기 방향으로 가면 결과가 커집니다. 줄이려면 반대로 갑니다(F-M6).

**L01-S09 뉴런 하나 계산하기**
- 새 코드: 약 4줄
- 입력: 입력 x1, x2, 가중치 w1, w2, 편향 b를 `Value`로 만들고 `n = x1*w1 + x2*w2 + b`를 계산해 그림 그리기.
- 보여야 하는 것: 곱셈 두 개와 덧셈이 이어진 그림, n의 값.
- 뜻: 뉴런은 "입력마다 가중치를 곱해 더하고 편향을 더한 값"입니다.

**L01-S09b tanh 붙이기**
- 새 코드: 약 5줄
- 입력: `tanh` 메서드 추가(`math.tanh` 이용, 결과의 재료는 self 하나). `o = n.tanh()`로 그림 그리기.
- 보여야 하는 것: 출력 o가 -1과 1 사이.
- 뜻: tanh(활성화 함수, 값을 -1~1로 눌러 주는 함수)의 기울기는 1 - o² 입니다.

**L01-S10 _backward를 + 와 * 안에 넣기 (긴 단계)**
- 새 코드: 약 8줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력: `__init__`에 `self._backward = lambda: None` 추가. `+`와 `*`에서 결과 out을 만든 뒤 `def _backward(): ...`를 정의해 `out._backward`에 넣습니다. 예: 곱셈은 `self.grad += other.data * out.grad` 와 `other.grad += self.data * out.grad`.
- 보여야 하는 것: `d.grad = 1.0; d._backward()` 후 바로 앞 노드들에 grad가 생김.
- 뜻: 노드마다 "내 기울기를 재료에게 나눠 주는 방법"을 스스로 압니다.

**L01-S10b tanh의 _backward**
- 새 코드: 약 3줄
- 입력: `tanh` 안에 `def _backward(): self.grad += (1 - t**2) * out.grad` 와 `out._backward = _backward`.
- 보여야 하는 것: `o.grad = 1.0; o._backward()` 후 n.grad가 1 - o² 와 같음.
- 뜻: S09b에서 말로 배운 tanh 기울기를 코드로 옮겼습니다.

**L01-S11 위상 정렬 (긴 단계)**
- 새 코드: 약 8줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)
- 입력: 재료부터 결과 순으로 노드를 줄 세우는 함수 `build_topo`(위상 정렬, topological sort, 재료가 항상 결과보다 앞에 오게 줄 세우기)를 만들고 `o`로 실행해 목록 출력.
- 보여야 하는 것: 맨 앞에 입력 값들, 맨 끝에 o가 있는 목록.
- 뜻: 거꾸로 돌면 결과부터 재료 쪽으로 차례대로 갈 수 있습니다.

**L01-S11b backward() 메서드**
- 새 코드: 약 4줄
- 입력: `backward()`에서 위상 정렬 목록을 만들고 `self.grad = 1.0` 뒤 `reversed`로 돌며 `_backward()` 호출.
- 보여야 하는 것: `o.backward()` 한 줄로 S07에서 손으로 채운 값과 똑같은 grad.
- 뜻: 역전파 자동화 완성.

**L01-S12 같은 값을 두 번 쓰는 버그**
- 입력: `a = Value(3.0); b = a + a; b.backward(); a.grad`
- 보여야 하는 것: `+=`가 아니라 `=`로 썼다면 1.0(틀림), `+=`라면 2.0(맞음).
- 뜻: 한 값이 여러 길로 영향을 주면 기울기를 더해야 합니다.

**L01-S13 더 많은 연산 (긴 단계)**
- 새 코드: 약 10줄 (긴 단계: 나누면 뜻이 끊겨 한 단계로 둡니다. 줄마다 한국어 풀이가 붙습니다)

## 7. 자주 막히는 곳

리서치 반영(`research/01_micrograd.md` 5절, GitHub 이슈와 유튜브 댓글 근거):
- `sum()`이 0(정수)부터 더해서 `int + Value` TypeError가 납니다. `__radd__`를 추가하거나 `sum(..., Value(0.0))`처럼 시작값을 줍니다(GitHub nn-zero-to-hero#41, 영상 1:54 부근 댓글). S14 전에 막힘 힌트로 미리 보여 줍니다.
- `float - Value` 오류는 `__rsub__`가 없어서입니다(영상 1:54:01 부근 댓글).
- grad 비우기(zero_grad)는 `loss.backward()` 앞에 와야 합니다(2:04:41 부근 댓글, micrograd#53, #25).
- 그래프를 그리기 전에 `backward()`를 빠뜨려 grad가 모두 0으로 보임(nn-zero-to-hero#40).
- graphviz는 시스템 프로그램과 파이썬 패키지 둘 다 필요합니다(댓글). CTO 환경 안내에 둘 다 넣어야 합니다.
- 학습 시간: 댓글들에 2시간 30분 영상에 4~5시간, 길게는 1주일 걸렸다는 보고가 많습니다. 이 앱의 예상 8~12시간과 어긋나지 않습니다.

교사 몽키 예상(강의 지식 기반):
- `+=`와 `=`의 차이(S12). 가장 흔하고 중요합니다.
- `Value + 숫자`(예: `a + 1`)가 에러: 숫자를 `Value`로 감싸는 처리가 필요하고, `1 + a`는 `__radd__`가 필요합니다.
- 클래스 안의 함수 안의 함수(`_backward`)가 낯섦. F-P6으로 돌아가 "함수도 값처럼 저장할 수 있다"를 먼저 봅니다.
- graphviz 설치 문제(맥미니). 환경 문제이므로 HELP로 보냅니다.
- 학습률 부호와 grad 초기화 빼먹기(S15, S16).
